# ORBIT

安装：`npm install`

本地启动：`npm run dev`

检查：`npm run typecheck`，`npm run build`。

Docker 启动：`docker compose up --build`，打开 http://localhost:8517 。

## 六面立方体导入

素材面板支持「六面立方体导入」：分别放入前 / 后 / 左 / 右 / 上 / 下六张正方形照片，导入器校验尺寸一致、缺面与重复方向；在立方体预览中可逐面旋转 / 翻转，整组校验通过并确认后才替换当前素材，未完成的输入保留在导入草稿中。

方案选择：**直接读取六面纹理**，不预转换等距全景。边界与角点依据空间方向跨面读取（双线性的四个采样点可落在相邻面，角点由主轴投影落到第三面），不靠单面拉伸掩盖缝隙；交互预览与高清导出共用同一方向与过滤规则。确认后保留原始六面与校准版本；在投影画面中点击即可反查并替换某一面（其余面校准保留），导出按目标清晰度直接读取冻结的六面版本，不落地低清预转换图。
